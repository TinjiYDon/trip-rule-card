# 规则卡 · 交稿说明

作品名：规则卡  
仓库：https://github.com/TinjiYDon/trip-rule-card（私有，已邀队友）  
一句话：在「立即预订」之前，把票务散文编译成可执行规则，告诉同一个人今天算什么票。

## 评委三问

1. **解决什么问题**  
   阻断下单的不是「去哪」，而是这个人今天能不能优惠、种草是否骗人、何时放票、优惠能否叠加。

2. **凭什么值得做**  
   儿童票身高/年龄不统一；短视频种草与在售条款常不一致。本仓库用公开官网页 + 种草对照句，报告见 `docs/report.html`。

3. **技术强在哪**  
   不是聊天套壳。六步：分句 → 抽槽 → 结构校验 → 修补 → 符号执行 → 对照朴素读法（只看种草 / 只读第一个数字 / 合取消融）。模型草案可选，过不了校验就丢掉。

## 现场演示（约 2 分钟）

```powershell
cd rule-card
python demo/server.py
```

打开 http://127.0.0.1:8765

1. 选「中国科学技术馆」：种草说免票，编译为半票（10 岁超过免票线，仍买优惠票）。  
2. 选「［留出］东方明珠」：1.25 米 / 7 岁 → 半票；把种草改成「全部免票」看冲突。  
3. 改票务原文任意几字，预存答案消失，证明不是写死馆名。  
4. 打开 `docs/report.html`：三路准确率与错因分布。

## 诚实边界（答辩必说）

- 准确率只对应当前语料，不是全国投诉统计。  
- 未标 `verified: true` 的是规则类型例句，不是现行票价。  
- 未接携程库存，不下单。  
- 默认离线可复现；大模型不是现场唯一路径。
