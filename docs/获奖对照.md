# 对照宣讲「怎样的作品能得高分」

出处：队内《云宣讲》第 12 页。总原则是：从问题出发，用数据说话，靠技术取胜。技术不是跑分，要落在交易前这一下。

| 评审问什么 | 本作品怎么答 | 还没做到、必须口头说清 |
|---|---|---|
| 为谁解决什么，边界在哪，怎样算成功 | 为即将买票的人和购票页。成功＝有标注的留出页上，编译执行比「只看种草」和「只读第一个数字」更接近标注。不做行程规划、不下单 | 13 条里已核对官网的只有 2 条，立牌页抽不出门槛 |
| 影响多少人，凭什么值得做，做完怎么看变好 | 儿童票身高/年龄不统一（中新网 2026-03-24）；种草和在售不是同一张表（新快报 2026-07-20 转述）。变好看评测表，不看口号 | 百分比是报道转述，不是我们清点的投诉库 |
| 比最朴素的做法强在哪，难点和取舍 | 朴素做法有两路：看见免票就下结论，以及只信第一个数字。合取规则再做一次消融：数字相同，但把「同时满足」改成「满足其一」。取舍：默认可离线复现；模型草案过不了结构校验就丢掉 | 抽取是规则模板，不是训练出来的模型。没写数字的页面会失败，失败显示为「没有可执行门槛」 |
| 关键路径能否当场演示，哪里没做 | `python demo/server.py` 走完：选馆、改身高、改原文、看三路结果、看六步轨迹和错因 | 没有接携程库存，没有全国馆，没有真下单。可选模型不作为现场唯一路径 |

答辩只回答三句：你在解决什么问题，凭什么说它值得做，技术上你强在哪里。
