# 四人分工

目录就是边界。不要改别人的目录，通过 `data/venues/*.json` 和 `compile_and_run()` 交接。

| 角色 | 目录 | 交付 | 怎样算做完 |
|---|---|---|---|
| 标注 | `data/venues/`、`data/schema.json` | 把种子例句换成当天官网原文，`verified` 改为 true。目标 30 条，其中约 8 条 `split: heldout` | `python eval/run_eval.py` 仍能跑，新增馆有 `gold.ticket` |
| 编译 | `rulecard/extract.py`、`rulecard/execute.py` | 新句式抽错时改抽取，不要把馆名写死 | `python -m unittest tests.test_pipeline` 通过 |
| 评测 | `eval/` | 错例归类：双门槛、种草冲突、放票读错。只报种子集和留出集，不外推全国 | 更新 `eval/latest.json`，README 里的数字和它一致 |
| 演示 | `demo/` | 门票页上的四格。留出馆在下拉框里以「留出」标出 | 现场从选馆到四格，不中断 |

GitHub 仓库先设为私有，避免交稿前公开。把四个人的用户名发来后再加 collaborator。现在还没有四个人的用户名，所以不能替他们建账号。

接口：

```python
compile_and_run(venue, age, height_m, benefits=[])
```

返回 `compiled.ticket`（free/half/full）、触发句、`baseline_ticket`、是否和 `gold` 一致。
