# 作品简介（飞书表单 · 直接粘贴）

作品名：规则卡  
队名：不鸣则已  
赛题：赛题二 · 旅行体验创新

**解决什么问题：**  
付款前「这个人今天到底算什么票」说不清——种草说儿童免费、页面可能是半票或双门槛；放票时刻和优惠能否叠加也散落在散文里。用户反复试错，平台有库存却难成交。

**面向哪类用户：**  
即将点击「立即预订」的出行人，尤其亲子出行；也可供购票页产品与客服核对条款。

**核心能力是什么：**  
1）把票务页散文离线编译成可执行规则并符号判定；2）与「只看种草」「只读第一个数字」对照并标出错因；3）预订前四格展示票种、种草冲突、放票、优惠叠加；4）可改原文的 LIVE DEMO，断网可复现。
