1. 问题与用户

阻断下单的往往不是攻略，而是付款前：这个人今天算免票还是半票、种草与条款是否一致、何时放票、优惠能否叠加。面向即将点「立即预订」的出行人（尤其亲子）。

2. 核心能力

离线六步编译执行
分句→抽槽→校验→修补→执行→对照
三路对照 + 错因
种草 / 首个数 / 编译
预订前四格 DEMO

3. 技术创新点

  • 神经符号分工：自然语言只提议结构，符号规则才下结论。
  • 结构校验挡住残缺规则；模型草案可选，过不了校验即丢弃。
  • 默认断网可演示，不把现场押在外网接口上。
