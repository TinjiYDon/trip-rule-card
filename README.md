# 规则卡

携程首届高校 AI Hackathon 作品。嵌在门票「立即预订」之前。

一个人、一天、一个景区：算什么票、种草和在售是否一致、何时放票、优惠能否叠加。散文先编译成规则再执行。对照方法是「看见免费就判免票」。

## 跑起来

```powershell
cd rule-card
python -m unittest tests.test_pipeline
python eval/run_eval.py
python demo/server.py
```

浏览器打开 http://127.0.0.1:8765

当前 8 条种子（含 2 条留出）：只看种草准确率 0.25，编译后执行 1.0，留出馆编译后执行 1.0。这只说明抽取器在这些句子上胜过关键词，不能写成全国成绩。换官网原文后数字会变，以重新运行 `eval/run_eval.py` 为准。

## 最终范围

做：规则结构、离线抽取、执行、留出馆评测、预订前四格演示。  
不做：行程规划、问道套壳、真下单、自训模型、把未核验例句说成官网现行价。

高分对照见 `docs/获奖对照.md`。四人目录见 `docs/分工.md`。

## 种子数据

`data/venues/` 里故宫一条按公开预约页整理，其余多条是公开报道里的规则类型，`verified` 为 false。标注同学替换成当天页面后再把 `verified` 改成 true。
